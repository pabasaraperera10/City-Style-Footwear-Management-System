# City Style Footwear Management System

A Java OOP-based inventory management system for a footwear store, with role-based access for Cashiers and Managers.

## About the Project

City Style Footwear Management System is a desktop application built using core Object-Oriented Programming principles to manage footwear inventory, sales, and stock — with separate access levels for Cashiers and Managers.

## Features

- Inventory management (add, update, remove stock)
- Sales/cashier operations
- Manager-level controls and reporting
- Role-based access for Cashiers & Managers
- Persistent data storage with MySQL via JDBC

## Tech Stack

- **Language:** Java (OOP)
- **Database:** MySQL
- **Connectivity:** JDBC

## Getting Started

```bash
Clone the repository
git clone https://github.com/pabasaraperera10/city-style-footwear-management-system.git

Navigate to the project directory
cd city-style-footwear-management-system

Import the database (MySQL)
Import the provided .sql file into your local MySQL server

Configure JDBC connection details in the config/DB connection class

Compile and run the Java application
```
